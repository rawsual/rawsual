# Rawsual - Portfolio Vidéaste

Site portfolio professionnel pour Rawsual, vidéaste indépendant spécialisé en réalisation, montage et storytelling visuel cinématographique.

## 🎬 À propos

Site one-page moderne et élégant présentant :
- Présentation du vidéaste
- Prestations (Réalisation, Montage, Étalonnage, Direction créative)
- Portfolio de projets vidéo (formats horizontal et vertical)
- Formulaire de contact

## 🚀 Technologies

- HTML5
- CSS3 (avec design responsive)
- JavaScript (vanilla)
- Intégration YouTube
- Formspree pour les formulaires

## 📱 Responsive

Le site est entièrement responsive avec une version mobile optimisée.
